# Scalaの書き方

> **TL;DR**: Scalaを書くときとレビューするときに読む。一般的な作法は書かず、pomesakaが選んだ書き方だけを置く。言語によらない分岐とコメントの決まりは`coding-policy.md`にある。

## 分岐

- `ifM`（条件の`IO[Boolean]`と2つの枝を引数で渡す形）は使わない。どちらが真の枝かを引数の順番で覚えないと読めないためだ。調べた結果を値にし、`match`で分ける
- 調べた結果から枝を選ぶ処理は、結果のenumのコンパニオンに`of`として置く。調べる処理（`IO`でファイルやDBを見る）は値を返すだけにし、枝を選ぶ所を1か所にする
- あるか無いかを調べる処理は、`IO[Boolean]`でなく、見つけた物を`IO[Option[A]]`で返す。真偽値を返すと、呼び出し側でもう一度読みに行くことになる
