# verify-guide

Claudeがアプリを起動したとき、そのリポジトリにアプリの動かし方の手順書があるかを、Claudeに伝えるMod。

## なぜ要るか

同梱の`/verify`は、リポジトリの`.claude/skills/`にある`verify`、`verifier-*`、`run-*`の手順書で起動し、無ければ動かせた手順を書いて残す決まりを持つ。ただ、`/verify`はClaudeのスキルの一覧に出ず、Claudeから呼べない。2026-11-18のxwbの作業では、誰も呼ばず、別のポートで起動して画面を操作する同じ手順を、セッションごとに10回以上書き直していた。

手順書を読むか書くかの判断は`verifier`のエージェント（`agents/verifier.md`）と`CLAUDE.md`が持つ。このModは、本人が忘れたときの網として、起動した時点で手順書の有無を伝える。

## すること

- メインかサブエージェントがBashでアプリを起動したら（`portless <名前> <コマンド>`、`playwright-cli open`、`npm run dev`のような開発サーバー、`vite`、`wrangler dev`、`cf dev`）、コマンドの結果に1文を添える
  - 手順書があれば、そのパスを示して、その手順に従うよう伝える
  - 無ければ、確かめ終えた後に`agents/verifier.md`の「手順書を残す」に従って書くよう伝える
- 伝えるのは、1つのセッションでリポジトリごとに1回だけ
- 探すのはリポジトリの直下の`.claude/skills/`だけ。モノレポのパッケージの下は、`verifier`が自分で探す
