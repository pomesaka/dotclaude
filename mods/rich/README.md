# rich

Claudeが`show`ツールを呼ぶと、カード、箱と矢印の図、Markdown、クリックで答える質問をターミナルに描くMod。ブラウザを開くほどではない説明に使う。使いどころと入力の書き方は`skills/explain/references/rich.md`に書いてある。

## 読み込み

マーケットプレイス`dotclaude`から入れる。手順は`mods/README.md`にある。

## 出し方

| `where` | 出る場所 | 操作 |
|---|---|---|
| `inline`（既定） | 会話の中の、ツールの行 | クリック |
| `pane` | 会話の横、または上の枠。`/rich-pane`で開き直せる | クリックと数字キー |

## 入力

```json
{
  "title": "出し方の比較",
  "where": "inline",
  "blocks": [
    { "type": "text", "text": "Markdownの文章や箇条書き" },
    { "type": "cards", "cards": [{ "title": "案A", "lines": ["ふつうの行", { "text": "利点", "tone": "good" }] }] },
    { "type": "diagram", "nodes": [{ "id": "a", "title": "Claude", "note": "中身を決める" }, { "id": "b", "title": "Mod" }], "edges": [{ "from": "a", "to": "b", "label": "データ" }] },
    { "type": "question", "key": "next", "question": "次にやること", "options": ["push", "待つ"] }
  ]
}
```

`cards`のブロックに`key`と`question`を付けると、カードが選択肢になる。題名を押すと、そのカードの`value`（無ければ題名）が答えとして送られる。カードで比べた案を、下に質問の枠でもう一度並べなくて済む。押せるのは題名だけで、枠の中のほかの行は押せない（ボタンの中に置けるのは文字だけで、枠の付いた箱ごとは押せないため）。

タブは`{ "type": "tabs", "tabs": [{ "label": "案A", "blocks": [...] }, ...] }`。見出しを押すと下の中身が入れ替わる。中に置けるのは`text` `cards` `diagram`だけ。

`tone`は`plain` `good` `warn` `dim`のどれか。入力が合わないと、どこが悪いかを書いた文でツールが失敗する。

## 質問

質問は私の番を止めない。答えは利用者の次の発言として届く。

```
【出し方の比較 への回答】
1. 次にやること: push
```

質問が1つなら、選んだ時点で送る。複数なら、すべて選ぶと「回答を送る」が出る。答えを送ると質問は閉じて、選んだ答えに印を付けた表示だけが残る。答え直すことはできない。

質問の状態は`$.store`（セッションをまたいで残る）に持つ。セッションを開き直しても、答え済みの質問は閉じたままで、選んだ答えを読める。

| 保存の状態 | 行の見え方 |
|---|---|
| `open:<id>`がある | まだ答えていない。ボタンを押せる |
| `answer:<id>`がある | 答えた。選んだ答えに印を付けて見せる。ボタンは出さない |
| どちらも無い | 「この質問は閉じています」と出す。古くて消えたもの、この仕組みより前に出したもの |

未回答の印は30件、答えの記録は50件まで。超えたら古いものから消す。`<id>`は、会話の行ならツール呼び出しのID、paneなら`rich`。

## 図

箱は矢印の向きに沿って左から右へ並ぶ。位置はModが決める。線と枠は`Raster`に描き、ラベルは`Text`を重ねる。`Raster`には幅1の文字しか置けないためで、こうすると日本語のラベルを置ける。

描けるのは横の線、縦の線、直角の曲がりだけ。幅が足りないと右側が切れて、その旨が図の下に出る。

`Image`は使っていない。Claude Codeはtmuxの中で絵を描かない（v2.1.295で確認）。

## 開発

```bash
claude plugin validate mods/rich
claude plugin test mods/rich
```

型検査は、Modを一度読み込むと生成される`tsconfig.json`で`bunx tsc -p mods/rich`。
