# budget

サブスクリプションの使用率の枠（週、5時間）に予算を1つ置き、使用率が予算に達したら、予算を置いたセッションに止まるよう伝えるMod。週末の改善の時間（`improve-week`のスキル）が、予算の分だけ自分で作業を進め、達したら区切って止まるために使う。

## 予算

予算は、Claude Codeが測った枠の使用率（`session.measure`の`rateLimits`の`percentUsed`）に置く閾値だ。`$.store`の`budget`に1つだけ持つ。

| 欄 | 中身 |
|---|---|
| `kind` | 枠。`seven_day`（既定）か`five_hour` |
| `percent` | 閾値。0より大きく100以下 |
| `sessionId` | 知らせを受けるセッション。予算を置いたセッション |
| `resetsAt` | 期限。置いたときの枠の`resetsAt`を写す |
| `notice` | `watching`か、`notified`（知らせた時刻と、届いたか） |

守る決まりは次のとおり。

- 予算は1つだけ。置き直すと前の予算は消える
- 使用率が閾値以上になったら、1回だけ知らせる。知らせた印を`notice`に置き、2回目は知らせない
- 期限を過ぎたら外す。枠が新しくなると、閾値の意味が無くなるためだ

## ツール

| ツール | 動き |
|---|---|
| `set_budget`（`percent`、`kind`） | いまの枠の値を読み、期限を写して予算を置く。枠の値が無い（サブスクリプションでない、最初の応答の前）、期限が無い、すでに閾値以上、のときは拒む |
| `clear_budget` | 予算を外す |
| `read_budget` | 予算といまの枠の値をJSONで返す。期限を過ぎた予算は外してから返す |

## 知らせ方

使用率の枠はアカウントのもので、どのセッションにも同じ値が届く。このModは全部のセッションで、`session.measure`の`changed`に`rateLimits`が入るたびに予算と比べる。最初に越えたと気づいたセッションが、次をする。

1. `$.store`に知らせた印（届いたかはまだ偽）を置く。ほかのセッションが続けて知らせるのを減らすため、届ける前に置く
2. 予算を置いたセッションに、達したことと、作業を区切って報告し、止まるよう伝える文を届ける
   - 自分のセッションなら`$.prompt.submit`で会話に文を足す。送信はいまのターンが終わるまで返らないので、待たずに投げる
   - 別のセッションなら`$.session.send({ to: { sessionId } })`で送る。`mods/questions`がほかのセッションへ答えを送るのと同じ仕組みだ。相手が閉じていて届かなくても、印は残す。止める作業がもう動いていないためだ
3. 届いたかを印に書き、気づいたセッションの画面に、toastで達したことと、届いたかを出す。自分の会話へ送ったときは、送信が返ってから書く。その間に予算が置き直されたか外されていれば、印は書かない

2つのセッションがほぼ同時に測ると、両方が印を置く前に読み、2回知らせることがある。`$.store`には比べて書く操作が無いので、防いでいない。
