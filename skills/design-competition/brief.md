## モックの形

- 担当のディレクトリの `index.html` に、HTML、CSS、素の JavaScript で作る。フレームワークとビルドは使わず、外部のネットワークにも取りに行かない
- `shared/` の CSS とデータを読む。データの取り方は `shared/` のファイルの冒頭にある
- 右下に `<div class="mock-badge">モック（架空のデータ）</div>` を出す
- 保存は画面の中だけでよい（読み込み直すと戻る）
- 担当のディレクトリの外のファイルは変えない
- 作ったら、コンペのフォルダで `bun ~/.claude/skills/design-competition/check.ts <コンペのフォルダ> --mocks <担当のキー>` を走らせ、横あふれとエラーが無くなるまで直す。Playwright は <Playwright の入ったプロジェクトのディレクトリ> で走らせると見つかる
