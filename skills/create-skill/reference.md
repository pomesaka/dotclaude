# スキルのfrontmatterのリファレンス

## 欄の一覧

| 欄 | 説明 |
|---|---|
| `name` | スラッシュコマンドの名前。省くとディレクトリの名前になる。小文字の英数字とハイフン、64文字まで |
| `description` | 何をするスキルか。モデルがスキルを使うかどうかを決める材料になる |
| `when_to_use` | どんなときに使うか。`description`と合わせて1,536文字までがモデルに渡る |
| `argument-hint` | 補完に出る引数の手がかり。例: `[issue-number]` |
| `disable-model-invocation` | `true`で、モデルが自分では呼ばなくなる。ほかのスキルからの`Skill`の呼び出しも止まる |
| `user-invocable` | `false`で、スラッシュのメニューに出なくなる |
| `allowed-tools` | スキルの実行中に、許可の確認なしで使える道具。例: `Read, Grep, Bash(npm *)` |
| `model` | スキルを実行するモデル。省くと会話のモデルを継ぐ。固定する場面は`SKILL.md`の「model」にある |
| `context` | `fork`で、会話の履歴を持たないサブエージェントの中で実行する |
| `agent` | `context: fork`のときのエージェントの種類。`Explore`、`Plan`、`general-purpose` |

どの欄も省ける。`description`は書く。

## 使える変数

| 変数 | 説明 |
|---|---|
| `$ARGUMENTS` | 引数の全部（空白で区切られる） |
| `$0`、`$1`、… | N番目の引数（0から数える） |
| `${CLAUDE_SKILL_DIR}` | `SKILL.md`があるディレクトリのパス |
| `${CLAUDE_SESSION_ID}` | セッションのID |

## 読み込みの時点での埋め込み

感嘆符とバッククォートで囲んだコマンドは、スキルを読み込んだ時点で実行され、出力が本文に埋め込まれる。

```markdown
## 現在のdiff
!`jj diffu`
```

- コマンドの中でも`$ARGUMENTS`と`${CLAUDE_SKILL_DIR}`は置き換わる。`` !`${CLAUDE_SKILL_DIR}/start.sh $ARGUMENTS` ``で、引数ごとに処理を分けるスクリプトを呼べる（listenスキルで確かめた、2026-11-18）
- コマンドが0以外で終わると、スキルの呼び出しごと止まり、何が起きたかがモデルに届かない。読み込み時に呼ぶスクリプトは、失敗も`exit 0`で返し、出力の文で知らせる
- 上限は2分。長く動かすプロセスは、スクリプトの中で`nohup … &`で切り離し、準備ができるまで待ってから終わる

## プロンプトのキャッシュ

キャッシュは、プロンプトの先頭からの一致で効く。`context: fork`のスキルを繰り返し呼ぶときは、変わらない内容を先に、変わる内容を末尾に置く。

```
[変わらない] 基準の文書（読み込みの時点で埋め込む）
[変わらない] 手順
[変わる]     コマンドの出力（差分、ログ）
```

基準の文書を`Read`で読ませず、読み込みの時点で埋め込むと、道具の呼び出しの往復が減り、文書がキャッシュの効く先頭の部分に入る。基準の文書の埋め込みは、`review-code`のスキルが使っている。

```markdown
## 基準
!`cat ~/.claude/docs/coding-policy.md`

## 手順
...

## 変更差分
!`jj diffu -r main..@`
```

キャッシュから読んだ部分の費用は、Anthropic APIでは通常の入力の約1割で、キャッシュの寿命の既定は5分だ。Claude Codeがforkしたスキルにこの値をそのまま当てているかは、確かめていない。

埋め込んだ文書は、呼ぶたびに全文が入る。毎回要る文書だけを埋め込み、対象によって要るかどうかが変わる文書は、対象を見てから`Read`で読む。
