# Gotchaの追記

`$ARGUMENTS`の、実際に間違えた点を、関連するスキルの`Gotchas`の節に書く。

対象のスキルは、`$ARGUMENTS`に名前があればそれを使い、無ければ会話から決める。ファイルは`~/.claude/skills/<スキル名>/SKILL.md`で、編集は実体のパス（`~/github.com/pomesaka/dotclaude/skills/...`）で行う。

書く基準は`re`のスキルと同じにする。基準を1か所に置くため、`~/.claude/skills/re/SKILL.md`のStep 3とStep 4を読み、それに従う。このスキルで変わるのは、探す範囲と書き先だけだ。

- 先に対象のスキルの全文を読み、その点が本文の手順か既存の項目に含まれるかを見る。含まれるなら項目を足さず、伝わらなかった文を直す。`Gotchas`に同じ原因の項目が並んでいるなら、1つにまとめる
- 含まれないときだけ、`Gotchas`の節の末尾に`- **<原則を短く言った見出し>**: <原則と理由>`の形で足す。節が無ければ、ファイルの末尾に作る
- スキルに固有でない点（どの作業でも起きる、道具そのものの癖）は、スキルでなく`~/.claude/docs/`の当てはまる文書に書く。書き先は`re`のStep 2の表で決める

書いた後、どのファイルの何を足したか、直したかを1行で報告する。足さなかったときは、既にどこに書いてあったかを伝える。
